Workflows
Programmable step sequences (loops, data, hotkeys)
  • Build an ordered sequence (click → fill → wait for element → click…) and press ▶ Run to play it.
  • Or press ● Rec and just do the actions on the page — your clicks, typing and dropdown picks are captured as steps automatically.
  • Hover between steps for a + to insert one exactly there (e.g. a Delay).
  • Drag the ☰ handle to reorder steps.
  • Use ◎ to flash a step's element on the page.
  • Use ⚙ for run mode / hotkey / repeat / CSV data.

URL Shifter
Auto-redirect when the page URL matches
  • Click +, name the rule, choose a Trigger, then set a redirect to URL.
  • Trigger: URL matches — Exact / Partial match the page's path (e.g. /umrah/mutamer/add-mutamer); Partial matches anything starting with it. Contains / Not contains match anywhere in the full URL — useful for query strings or a domain fragment.
  • Trigger: Element appears on the page — pick (or type) a selector; the rule fires as soon as that element shows up, even if it's inserted dynamically after the page loads.
  • Redirect to can be a full URL or a path on this site (e.g. /umrah/mutamer-group).
  • Works with Angular's in-app navigation, not just full page loads — a rule fires once per page/route, so it won't loop.
