Auto Date Picker
Type DD / DDMM / DDMMYY / DDMMYYYY into any calendar field
  • Click into any date field, then type DD, DDMM, DDMMYY, or DDMMYYYY — Enter or Tab commits it (or just pause typing for 1.5s); Escape cancels.
  • Type two dates separated by a space (e.g. 25 01) to fill a date-range pair in one go — the second fills whichever calendar field comes next.

URL Shifter 

            
Auto-redirect when the page URL matches

          

          
        

        
    
          
  • Click +, name the rule, choose a Trigger, then set a redirect to URL.
    • 
          
  • Trigger: URL matches — Exact / Partial match the page's path (e.g. /umrah/mutamer/add-mutamer); Partial matches anything starting with it. Contains / Not contains match anywhere in the full URL — useful for query strings or a domain fragment.
    • 
          
  • Trigger: Element appears on the page — pick (or type) a selector; the rule fires as soon as that element shows up, even if it's inserted dynamically after the page loads.
    • 
          
  • Redirect to can be a full URL or a path on this site (e.g. /umrah/mutamer-group).
    • 
          
  • Works with Angular's in-app navigation, not just full page loads — a rule fires once per page/route, so it won't loop.
    • 
        

      

    


    

      

        
      

      
URL Shifter is a premium tool

      
Automatically redirect away from — or into — a page when its URL matches a rule. Enter your activation key in Settings to unlock it.

Translation Rules 

            
Field-to-field auto-translate, or auto-detect & translate any foreign text

          

          
        

        
    
          
  • Field to field — pick a source element and a target element, choose the languages, and whenever the source changes it's translated into the target automatically.
    • 
          
  • Auto-detect — pick (or type) a selector that may match many elements (e.g. a whole column of rows), or clear the selector entirely to scan the whole page; whenever foreign text appears there, it's detected and translated in place. Add more than one target language and it duplicates a translated row for each extra one.
    • 
          
  • Pick element to translate (button below) fixes one piece of text on the page right now, using your Settings > Extension language — nothing is saved.
    • 
        

      

    


    

      

        
      

      
Translation Rules is a premium tool

      
Configurable field-to-field auto-translate, plus auto-detect-and-translate for any foreign text on the page.
